Moving Average Crossover

This PowerLanguage demo uses two simple moving averages with adjustable periods. The chart marks the bar that triggers each signal. The code places a market order on the next bar.

Back to the Chart ↑
Entry
Fast MA crosses above slow MA
Exit
Fast MA crosses below slow MA
Periods
Fast 5 · Slow 13
View PowerLanguage Code 
Inputs: FastLength(5), SlowLength(13);
Vars: FastMA(0), SlowMA(0);

FastMA = Average(Close, FastLength);
SlowMA = Average(Close, SlowLength);

if MarketPosition = 0 and FastMA crosses above SlowMA then
    Buy ("MA-Long") next bar at market;

if MarketPosition = 1 and FastMA crosses below SlowMA then
    Sell ("MA-Exit") next bar at market;
